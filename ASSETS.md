# Aset dan lisensi

- `public/images/abe.png`: foto profil Abex untuk halaman Tentang.
- `public/images/*doodle*.webp`: ilustrasi dekoratif background; ditampilkan sebagai mask CSS.
- `public/images/cursor-butter.svg`: pointer butter berukuran 18px.
- `public/projects/jelajanime.webp`: screenshot proyek dari [abexziero/jelajanime](https://github.com/abexziero/jelajanime).
- `public/projects/aplikasi-kasir.webp`: screenshot proyek dari [abexziero/aplikasi-kasir](https://github.com/abexziero/aplikasi-kasir), menggunakan data contoh.
- `public/projects/*.svg`: ilustrasi demo, bukan hasil pekerjaan klien.
- `public/images/robin*`: ilustrasi Nightwing lama, tidak digunakan aplikasi. Hak publikasinya belum diverifikasi.
- Font Geist: SIL Open Font License 1.1, lihat `src/app/fonts/OFL.txt`.
- Font Parkinsans: SIL Open Font License 1.1, lihat `src/app/fonts/parkinsans-OFL.txt`.
- Logo teknologi dan sosial: [Simple Icons](https://github.com/simple-icons/simple-icons), CC0; lisensi di folder ikon masing-masing.
- `public/optimized/`: turunan WebP responsif yang dibuat saat build; tidak disimpan di Git.
